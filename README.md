# 🎮 MathSpin – Juego Educativo Interactivo

**MathSpin** es una aplicación educativa interactiva diseñada para ayudar a estudiantes de primaria a reforzar sus habilidades matemáticas de forma divertida y dinámica mediante retos, preguntas y sistema de puntuación.

---

## 📌 Descripción del Proyecto

MathSpin combina aprendizaje y juego para mejorar:

* ➕ Suma
* ➖ Resta
* ✖ Multiplicación
* ➗ División
* 🧠 Agilidad mental

El sistema permite a los estudiantes resolver operaciones matemáticas mientras interactúan con una interfaz moderna y amigable.

## ⚙️ Instalación y Ejecución (Modo Desarrollo)

### 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/Danna0327/mathspin.git
cd mathspin
```

---

### 2️⃣ Instalar dependencias del Backend

```bash
cd mathspin-backend
npm install
```

Ejecutar servidor:

```bash
node server.js
```

---

### 3️⃣ Instalar dependencias del Frontend

En otra terminal:

```bash
cd mathspin-frontend
npm install
npm start
```

---

## 🚀 Modo Producción

Para generar versión de producción del frontend:

```bash
npm run build
```

Luego integrar la carpeta `build` o `dist` con el backend para despliegue.
