2. CÓMO USAR (PARA USUARIOS FINALES)
================================================================================

REQUISITO ÚNICO: Node.js 18+ (https://nodejs.org/)

PASOS:
  1. Abre la carpeta RELEASE
  2. Haz DOBLE CLIC en "START.bat"
  3. Espera a que diga "🚀 Servidor escuchando en http://localhost:5000"
  4. Abre navegador → http://localhost:5000
  5. ¡Listo! Usa la aplicación
  6. Para detener: presiona Ctrl+C en la ventana de PowerShell

NOTA: La primera ejecución instala paquetes (2-3 minutos). Las siguientes son instantáneas.

4. CONFIGURACIÓN (.env) - CAMBIOS COMUNES
================================================================================

Edita el archivo ".env" en la carpeta RELEASE con Bloc de Notas:

📋 CAMBIAR PUERTO:
   PORT=5000              → PORT=8080  (usa cualquier número disponible)

📋 CONECTAR ARDUINO:
   SERIAL_PORT=NONE       → SERIAL_PORT=COM3  (o el puerto donde esté)

📋 CAMBIAR CREDENCIALES MONGODB:
   MONGO_URI=mongodb+... → Tu propia conexión MongoDB

📋 CAMBIAR CLAVE SECRETA JWT:
   JWT_SECRET=...         → Tu propia clave segura

8. TROUBLESHOOTING
================================================================================

❌ "Node.js no está instalado"
   ✓ Solución: Instala Node.js desde https://nodejs.org/

❌ "Puerto 5000 ya está en uso"
   ✓ Solución: Edita .env, cambia PORT=5000 → PORT=5001

❌ "Error al conectar a MongoDB"
   ✓ Solución: Verifica MONGO_URI en .env (debe estar correcto)

❌ "node_modules/ ocupa mucho espacio"
   ✓ Solución: Normal (~500 MB). Se descarga solo la primera vez.
   ✓ Para liberar espacio: Borra node_modules/ y ejecuta START.bat de nuevo

❌ "Quiero cambiar el comportamiento de Serial Port"
   ✓ Solución: Edita .env, cambia SERIAL_PORT=NONE → SERIAL_PORT=COM3 (o tu puerto)
